# TOOLS.md – Místní poznámky

Dovednosti definují _jak_ nástroje fungují. Tento soubor je pro _tvoje_ specifika – věci, které jsou jedinečné pro tvoje nastavení.

## Co sem patří

Věci jako:

- Názvy a umístění kamer
- SSH hosté a aliasy
- Preferované hlasy pro TTS
- Názvy reproduktorů a místností
- Přezdívky zařízení
- Cokoliv specifického pro toto prostředí

## Příklady

```markdown
### Kamery

- obyvak → Hlavní prostor, širokoúhlý 180°
- vstupni-dvere → Vchod, spouštěno pohybem

### SSH

- home-server → 192.168.1.100, uživatel: admin

### TTS

- Preferovaný hlas: "Nova" (teplý, lehce britský)
- Výchozí reproduktor: Kitchen HomePod
```

## Proč odděleně?

Dovednosti jsou sdílené. Tvoje nastavení je tvoje. Oddělení znamená, že můžeš aktualizovat dovednosti bez ztráty poznámek a sdílet dovednosti bez prozrazení své infrastruktury.
